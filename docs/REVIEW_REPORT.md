# Review report and implementation plan — The Quackenbush Journeys, 1907–1908

Synthesis of three independent reviews of `index.html` and its data pipeline (branch `claude/quackenbush-alaska-maps-f7gnj6`, commit `50a3c59`), prepared 18 November 2026 by the synthesis editor of the workflow.

Inputs: a UX / cartographic review (findings F01–F17), an academic review by a historian of science / historical GIS / network analysis (A1–A18), and a WCAG 2.2 AA audit with axe-core 4.10.2 and manual keyboard probes (A11Y-01–A11Y-24). The three reviews did not edit any project file. This synthesis edits nothing but this file; every claim it adopts from a review that bears on source fidelity was re-checked against `data/source/` and the GNIS file (section 6).

Conflicts between reviews were resolved in this order: (1) fidelity to the five supplied sources and the named gazetteers, (2) clarity for a researcher meeting the site for the first time, (3) accessibility, (4) restraint of design.

---

## 1. Executive summary

**What holds.** The scholarly apparatus is sound and unusual: three voices (verbatim / researcher's summary / editorial note, plus annotation and the model's own notes) are typed in the data and distinct on the page; every network tie carries its quotation and the build verifies it; contradictions are left standing and absences are registered; every coordinate cites a gazetteer record; the hash router, Back/Close and previous/next work on every page. None of the 59 findings asks to change these foundations.

**What fails, in four groups.**

1. *The journey cannot be followed.* Markers carry no sequence numbers, connectors no direction, and there is no step-through; 1907 and 1908 overprint on Seattle–Nome, Nome–Keewalik, New York–Seattle and Keewalik–Elephant Point; a place visited in both years hides its second visit as a 4 px dot; labels pile up around Kotzebue Sound; the legend covers data and there is no scale bar on a map argued in miles (F02, F03, F08, F09, F13). Two connectors draw through-routes the one itinerary source denies — Solomon River→Keewalik and Candle→Elephant Point — and a model note describes a "15-mile spur" that is not drawn (A2). The panel toggle is unclickable because the Leaflet zoom control sits on top of it (F01, A11Y-15).
2. *"Unlocated (not drawn)" is three bare links.* Yet each unlocated place carries verifiable spatial statements ("some two hundred miles up the Yukon River from Nome"; "only 30 miles from Stone's camp"; "Mr. Grants camp on big bone beach"; "his ranch near Nome"), Coffee Creek has exactly six GNIS homonyms, and one place record says "the map shows a label" when it shows nothing (F04, A3, F16).
3. *Access.* The 41-stop list, the 99-item archive list, the 47 network nodes and all 68 Leaflet paths are mouse-only; seven `<select>` filters have no name; route changes move no focus and never change `document.title`; there is no skip link, no live region and no `prefers-reduced-motion` handling; in the dark scheme four of the five voice blocks render at 1.2–1.8:1 because hard-coded hex colours override the token rules (A11Y-01…24, F05, F06, F11, F15). Baseline: axe light scheme 31 failing nodes across 7 rules; dark scheme 2 AA contrast failures and 8 `link-in-text-block` failures.
4. *An unverified class of quotation.* Only tie quotations and Tale excerpts are build-verified; roughly 470 quoted fragments in model notes, place/stop "why" fields, findings, roles and published excerpts are not, and spot checks show silent emendations ("likght"→"light", "Taken by for"→"Taken for", "Exchscholtz…CHoris"→corrected) that an edition advertising verbatim fidelity cannot carry (A1). A handful of ties over-read their evidence; affiliation edges copy the wrong evidence across institutions; stated ties carry no date although every one rests on a dated document (A4, A5, A10).

**New networks.** The user asked for additional networks showing different relationships. The reviews agree that four can be built now without a single new fact: a funding-flow view from the attested sums (A7), a co-attestation view from the existing edge list (A9), a dedicated person–institution bipartite view with stated/inferred affiliations (A5, A10a), and a derived name-mention layer clearly labelled as automatic (A10d). Each must display its evidence rule and its caveat; derived relations are labelled "derived", never "asserted" (rule 4). The document-transmission network (A8), the person–place view (A10b) and an object/specimen layer (A18) are sound proposals deferred to a later cycle because they need substantial new hand-authoring.

**Decisions.** Of 59 findings, 40 are adopted as proposed, 17 adapted (the table in section 3 says how and why), and 2 deferred whole (A8, A18); parts of 11 others are deferred (section 5).

**Plan.** Four work packages executed by four agents in this order, each committing before the next starts: **C_data_networks** (12 items) corrects the data and adds the network views, so that everything downstream builds on verified data; **B_map** (11 items) makes the journey legible and gives the unlocated places an honest cartographic form; **D_design_nav** (9 items) adds the reading guide and glossary, fixes navigation, tokens, density and responsive layout; **A_accessibility** (11 items) sweeps everything built so far for WCAG 2.2 AA, makes map and network keyboard-operable, and re-runs axe against the committed baseline. Section 4 gives each item an unambiguous spec and an acceptance check.
